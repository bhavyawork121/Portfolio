# 🚀 Bhavya's Portfolio

![Portfolio Banner](public/images/banner_placeholder.png) <!-- Ideally we'd have a banner here -->

> "Building digital experiences that matter."

Welcome to my personal portfolio website! This project showcases my journey as a developer, highlighting my projects, skills, certifications, and professional experience. It is designed with a focus on **immersive user experience**, **responsive design**, and **interactive elements**.

## ✨ Features

*   **🎨 Dynamic UI/UX**: Built with a sleek, modern, and dark-themed aesthetic using **Tailwind CSS**.
*   **🚀 Interactive Elements**: Features smooth scroll animations, interactive cards, and a dynamic "scroll rocket" mechanic powered by **Framer Motion**.
*   **📱 Fully Responsive**: Optimized for all devices, from large desktops to mobile phones.
*   **⚡ High Performance**: Built on **Next.js** for blistering fast load times and SEO optimization.
*   **🌙 Clean Code Architecture**: Modular component structure for easy scalability and maintenance.

## 🛠️ Tech Stack

This project is built using the latest modern web technologies:

*   **Framework**: [Next.js 16](https://nextjs.org/) (React)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **Animations**: [Framer Motion](https://www.framer.com/motion/)
*   **Icons**: [Lucide React](https://lucide.dev/)
*   **Deployment**: [Vercel](https://vercel.com/) (Recommended)

## 📂 Project Structure

```bash
portfolio/
├── app/                  # Next.js App Router pages and layouts
├── components/           # Reusable UI components (Hero, Projects, Skills, etc.)
│   ├── ui/               # Primitive UI elements (Buttons, Cards, etc.)
├── public/               # Static assets (images, icons)
├── hooks/                # Custom React hooks
└── lib/                  # Utility functions
```

## 🚀 Getting Started

Follow these steps to run the project locally:

1.  **Clone the repository**
    ```bash
    git clone https://github.com/bhavyawork121/Portfolio.git
    cd portfolio
    ```

2.  **Install dependencies**
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  **Open your browser**
    Navigate to [http://localhost:3000](http://localhost:3000) to see the site live!
